# LEGS:ON web – produktová vize

Živý dokument. Mění se jen po dohodě; každá změna má záznam v `ROZHODNUTI.md`.

## Proč web existuje
Podcast má 157 dílů (11/2026) rozházených po platformách, ale žádné místo, které by bylo jeho. Web má být domovem podcastu: přivést nové posluchače z vyhledávání, převést je na předplatitele na Herohero a dát partnerům důvod ke spolupráci. Detailní cíle a požadavky: `ZADANI.md`.

## Pro koho
1. **Stálý posluchač** – nový díl, archiv, hosté.
2. **Cyklista z Googlu** – hledá téma, jezdce nebo závod; vstupuje přes článek, profil hosta nebo díl.
3. **Partner** – značka nebo obchod, který zvažuje spolupráci.

## Hlavní tok
Google → článek / host / díl → přehrát → `/predplatne` → Herohero.

## Pravidla, která platí
- Každé „Předplatit“ vede na `/predplatne`, na Herohero se odchází jen odtud a s UTM.
- Minimum ruční práce pro tvůrce: obsah teče z RSS feedu sám; co vyžaduje týdenní ruční práci, potřebuje silný důvod.
- Archiv se nemaže: díly od roku 2021 jsou hodnota webu i pro SEO. Slugy existujících stránek se nemění.
- Desktop zachovává pořadí čtení z mobilu.

## K probrání (principy z nhl-momentum, které je potřeba přeložit)
- **Vizuál místo textu?** V nhl-momentum platí, že text je výjimka. Tady jsou články hlavní zdroj návštěv z vyhledávání a jsou z podstaty text. Kde má platit vizuál (díly, hosté, statistiky pro partnery) a kde text (články)?
- **Kontext místo holých čísel?** Kde web ukazuje čísla (počty dílů, statistiky pro partnery), mají mít srovnání nebo vývoj?
